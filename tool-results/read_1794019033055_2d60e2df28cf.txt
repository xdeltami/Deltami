   674→## Arsitektur dunia sambung (v29) - tanpa ID manual, tanpa teleport API, anti-lag
   675→
   676→- SATU place, SATU jenis server. Pusat Kota di koordinat 0; setiap dunia

   678→- Masuk/pulang/kunjung = teleport CFrame server: tanpa loading screen, tanpa
   679→  ReserveServer, tanpa MemoryStore, tanpa kegagalan TeleportService. Seksi
   680→  pemilik TETAP ADA selama ia online - pulang ke kota lalu kembali = dunia
   681→  persis seperti ditinggal (termasuk isi meja semai).
   682→- Anti-jatuh saat streaming: SafeFloor raksasa (8000x1600, tak ter-stream),
   683→  anchor root 1,1 dtk saat tiba, RequestStreamAroundAsync, watchdog Y<-20
   684→  mengembalikan ke titik tiba.
   685→- Kunjungan: pemain di server yang sama -> langsung; pemain offline -> seksi
   686→  hantu baca-saja dari DataStore AKM_Dunia (auto-hancur 120 dtk kosong);
   687→  pemilik kembali masuk -> hantu otomatis jadi dunia miliknya.

   689→  DuniaLogic), save tiap 60 dtk bila berubah + saat keluar game + BindToClose.
   690→  Bila DataStore gagal, dunia tetap bisa dimainkan mode sesi (tanpa menimpa

   693→  server per-seksi dengan pesan jujur.
